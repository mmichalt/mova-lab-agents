# mova-lab-agents

An independent AI-assisted content-generation service for Mova-Lab, a Ukrainian
speech-therapy application. The project also serves as a practical introduction
to agent orchestration using explicit Node.js, TypeScript, and Express functions.

The repository is currently in the planning stage; no service is implemented.
Generated material will require human review and will never be published
automatically.

## Planning documents

- [Architecture and learning plan](docs/architecture-plan.md) — architecture,
  ten implementation stages, API and domain contracts, reliability, testing,
  security, and the concepts introduced at each stage.
- [Implementation backlog](docs/backlog.md) — 28 unstarted tickets with
  dependencies, acceptance criteria, and verification steps.

Start with milestone 1 in the backlog. It delivers standalone Ukrainian recording
exercise proposals for Р and Л before adding application integration, durable
workflows, or queues.
